A program that writes one funny line in the voice of a smug, judgmental self-checkout machine to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Run it:

```sh
python3 main.py
```

The entry is a single line of 90 characters, inside the 1–200 character gate: a till that has stopped scanning groceries and started documenting a hostage situation with live cultures.
